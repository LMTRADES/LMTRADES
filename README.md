## Featured Pillar Projects

Here are the key projects that showcase my skills.

### 1. Multichain MEV/DEX Arbitrage Scanner (v2.0)
This is a production-grade, automated trading system that simultaneously scans 7 EVM blockchains (including Arbitrum, Polygon, and Base) and 15+ DEXs for HFT arbitrage opportunities.

* **High-Performance:** Scans all 7 chains concurrently in **~3.87 seconds**.
* **v1.0 (Scanner):** A high-speed data pipeline to identify opportunities.
* **v2.0 (Automated Trading):** A full execution engine with wallet management, risk controls (dry-run mode), and **Flashbots integration** for MEV protection.
* **Tech:** `Python`, `Asyncio`, `Multiprocessing`, `web3.py`, `Alchemy`, `systemd`

<br>

### 2. AI On-Chain Auditor (In Development)
This is a novel security and analysis tool that uses a fine-tuned local LLM (Phi-3/Llama-3) to audit smart contracts for risk.

* **Custom Data Pipeline:** Scrapes and processes thousands of verified smart contracts from Etherscan/Arbiscan to create a unique fine-tuning dataset.
* **AI Engine:** Fine-tunes a local LLM to understand Solidity patterns, identify potential vulnerabilities, and flag high-risk functions (e.g., rug pulls, unsafe external calls).
* **Application:** A CLI tool that takes a contract address, feeds it to the local AI, and returns a human-readable risk analysis.
* **Tech:** `Python`, `Ollama`, `Unsloth`, `web3.py`, `LangChain`
